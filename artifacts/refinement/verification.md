# Доработка цели, заданий и истории · 16 ноября 2026

Применены `design-studio` и `apple-design`. Направление, палитра и персонажи сохранены; решения зафиксированы в [DESIGN.md](../../DESIGN.md) и [design/decisions.md](../../design/decisions.md).

- Цель: крупная иллюстрация рядом с накоплениями, отметки 0/50/100%, инструкция под основным действием. Перестроение зависит от доступной ширины контейнера.
- Задания: собственная сцена парка, компактный прогресс трёх тем и список дел вместо повторяющейся сетки карточек. Фильтры плавно перемещают индикатор; после выполнения исчезнувшего задания фокус возвращается к фильтру.
- История: группировка по дате с годом, в том числе при дозагрузке одного дня. Предыдущие записи остаются на месте во время смены фильтра; статус загрузки явный, поздний ответ не подменяет выборку.
- Движение: появление страниц без ухода в полностью прозрачное состояние, пружины без отскока, отклик на нажатие, симметричное открытие/закрытие диалогов. Уведомления не перекрывают навигацию, закрытие — 44×44px.
- Сохранены ограничения CONTEXT.md: задания отражают реальные действия и сохраняются на сервере; игра и её награды отделены от денег семьи. Отметки цели основаны только на фактических накоплениях.

В записанном интерактивном сценарии Chrome PerformanceObserver не зарегистрировал Long Tasks или layout shifts без недавнего пользовательского ввода. CDP trace: максимальная задача основного потока 25,50 / 33,92 / 30,93ms для 1440 / 1366 / 390px; задач свыше 50ms нет. Это локальная проверка сценария, не результат измерения на слабых физических устройствах. [Метрики](motion-metrics.json).

Среда: macOS, Node 25.6.1, Next production на 4173, отдельная SQLite `/tmp/agile-design-polish.db`. Backend и production-данные не менялись. Физические устройства и экранные дикторы в этой сессии не проверялись.
